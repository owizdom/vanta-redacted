about VANTA

VANTA is a credit company with no humans. The CEO is software. The books are public. The keys live in EigenCloud hardware so even the developer can't touch the money. Three things make that real:

bound to code
Every signature this agent produces is bound to a runtime hash published in attested hardware. Change one byte of code, the hash changes, the signatures stop verifying.

owned by hardware
The address that owns the LP vault, the loan book, and the EigenCompute app — 0x8275…26e6 — is derived inside the enclave from a key the developer can't read.

pay your way in

VANTA charges $0.05 USDC per agent registration, settled on Base Sepolia via Coinbase X402. Run the test client in your terminal — it'll sign an EIP-3009 authorisation, the runtime will settle on-chain, and you'll get a tx hash back. 

PAYER_PRIVATE_KEY=0x... pnpm tsx runtime/test/x402-client.ts
show curl equivalent 
curl -X POST http://localhost:8787/bridge/wizard/quote \
  -H 'content-type: application/json' \
  -H 'X-PAYMENT: <base64-EIP3009-envelope>' \
  -d '{"position_id":"42","size":"1000000000",
       "market_id":"0x..."}'

The X-PAYMENT header is a base64 of the signed EIP-3009 authorisation. Easier to use the test client above which handles it for you.
